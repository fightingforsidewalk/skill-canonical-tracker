# Denominator moves, worked

The headline percentage is only worth reading if a reader can audit how it moved. Every
move is a dated parenthetical on the figures row itself. Five shapes cover almost everything.

## 1. A close on proven evidence
`| **Launch progress** | **86%** — 69 of 80 *(9-02: B65 ✅ — closed on the human's production walk, 68→69.)*`
Numerator +1. Denominator unchanged. The glyph flipped in the same edit; the row left the
open table and joined the closed index (heading count +1).

## 2. A new item on a feature ruling
`*(8-21: B64 MINTED — the human's ruling; 78→79, and the headline dips a point on committed work with nothing regressed.)*`
Denominator +1, numerator unchanged, **headline falls**. Say so. The dishonest alternative
is parking committed work in a later tier so the number holds.

## 3. Open → in progress
`| **Counts** | 73 ✅ · 8 🟡 · 21 ⬜ … *(8-21: B64 ⬜→🟡 — built and shipped; open on one named behavioural check.)*`
Counts recompose; **no percentage moves anywhere**. In-progress is not done.

## 4. A struck item
`*(8-17: C4 STRUCK — covered by B35's final form, live-tested; denominator 100→99. Repository scrub certified zero; document scrub this sync.)*`
Denominator −1. Not struck until one content search across the repository and every
document comes back empty.

## 5. A tier move
`*(8-08: DENOMINATOR MOVE, the human's ruling — three activated later-tier items now ride the launch bar: 69→72; the point it cost is the finish line getting honest.)*`
The rows physically move. The percentage falls because the bar now measures the work
actually being done. **Promote or demote, never annotate.**

## What never moves the numerator
A doc bump. A design approved. A prompt issued. A handback that *says* it closed something
— that is a claim to verify, not a receipt. Only proven closes count.
